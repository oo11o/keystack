Secrets

Values a stack can reference as $secret_<name> — for example a name of runToken is used as $secret_runToken. They are masked in toasts, and they never touch stacks.json.

This is not encryption. An extension has no server, so these sit in plaintext on this machine and anyone with devtools can read them. What it does buy: they stay out of git, and — unlike config/*.json — no web page can fetch them.
